# Custom-Macropad
This is a custom macropad that i am making to make navigating in fusion 360 easier in terms of just needing the keyboard and the macropad for most basic stuff. I am building this because I like having my mouse available to do actual drawing and design instead of having to change camera placement and stuff and I feel like I could get things done quicker. Another reason im building this is that I think that this is a cool project topic and I also just want to make something and there is a tutorial. I also wanted it to solve a problem so thats how I got the idea to make it control fusion 360. The code hasn't ever been tested but it is there and I will make the code better once I build the actual project.
